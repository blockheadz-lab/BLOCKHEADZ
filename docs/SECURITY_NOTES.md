# Security Notes

This repository separates public review material from unrevealed production material.

## Publicly Safe

- simplified p5.js/WebGL demo
- fixed tunnel
- three demo character presets
- public contract source
- project documentation

## Not Public Before Reveal / Mint

- final trait pools
- rarity weights
- production seeds
- metadata generator
- final renderer
- whitelist lists
- holder snapshots
- private APIs
- `.env` files
- RPC keys
- deployment private keys
- unrevealed images/videos

## Contract Review Checklist

Before mint, publish:

- final NFT contract address
- final reward contract address
- Etherscan verified source links
- ownership / multisig proof
- royalty recipient proof
- Chainlink VRF consumer and subscription proof
- audit reports or public review notes
- final immutable/locked configuration transaction where applicable
